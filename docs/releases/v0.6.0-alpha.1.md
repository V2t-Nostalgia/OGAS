# OGAS v0.6.0-alpha.1

Source alpha, signed Git checkpoint and research-evidence publication.
Python package version: `0.6.0a1`. No installer build, binary distribution or
GitHub Release is part of this publication.

## Changes From v0.5.10

- A semantic action registry and Execution Broker boundary, typed backend
  evidence, capability overlays, request tracking and locked ordered sequences.
  Research strategy uses the boundary; economy/fleet legacy dependencies remain
  explicitly allowlisted rather than being silently declared migrated.
- A version-bound Native Runtime on the existing `CGameIdler` game-thread route,
  self-registering action modules and descriptors, and the common
  `Prepare -> IsValid -> PostCommandToSession -> Verify` execution structure.
  Unknown modules stage under `etc`; applications do not receive raw hook APIs.
- Additional fleet, construction, market, governance, leader, diplomatic and
  other command research. Runtime declarations, captured structures and
  production availability remain different sets.
- Automated SDK recovery using Linux ELF symbols/serializers, reference and
  Windows matching tools, metadata generation and the shared NativeCommandBuilder.
  MIT upstream attribution is preserved; this does not replace OGAS with a
  different MCP server or execution queue.
- Bounded non-submitting batch/incremental legality probes, native producer
  queries, script/native constraint planning and reusable coordinate values.
  The revision-7 research codec adds strict signed i64, including negative
  coordinates and full-range wire/JSON round trips, without arbitrary writes.
- Long-running command/payload/state capture, rotation/checkpoints, Observe
  monitoring, process-external CPU profiling and sampled-stack flame graphs.
  Native UI messaging and observer-country takeover remain research prototypes.
- OGAS branding, bilingual project/contributor/developer entry points, current
  metadata and a separate evidence archive. The old detailed README is preserved
  at the signed `v0.5.10` history, not discarded.

## What Has Actually Been Verified

| Level | Evidence and limit |
| --- | --- |
| 4.4.6 live execution | Historical carrier/proxy trials and selected native actions on exact Linux/Windows builds; see the per-action documents, not a blanket platform guarantee |
| 4.5.2 native legality | Cumulative class-deduplicated Linux evidence: 310 constructed, 174 populated/IsValid-tested, 105 ever true. No Post/Execute in those acceptance probes; some classes are UI tracking, not strategic tools |
| 4.5.2 offline recovery | 351 catalog entries; 267 complete named layouts in the latest coordinate study; 166 types / 2,548 candidate plans pass the research codec preflight |
| Current native execution admission | Linux declarations are pending or capture-staged; Windows move remains pending. Historical `live_verified` must not override current-build gates |

The [acceptance record](../runtime/PRODUCER_VALIDATION_ACCEPTANCE_4_5_2.md)
preserves the initial scheduling rejection and the separately authorized
corrected session. The [coordinate record](../runtime/COORDINATE_VALUE_REUSE_4_5_2.md)
distinguishes offline construction/codec work from game execution. Normal
IsValid=false, no candidate, missing semantics and ABI/lifecycle gaps are not
interchangeable outcomes.

## Known Limits

This is not complete 4.5.2 gameplay automation. Do not assume old packet builders,
old addresses or old captured bodies are valid on a new game build. Broad
multi-empire autonomous governance, complete Broker migration, a complete
rules solver and universal mod support are not finished. Native UI presentation
art is excluded from the current tree pending redistribution review; local
originals and earlier history remain intact.

Research uses strict object/layout/lifecycle/version/state gates. Recovery and
legality do not establish execution, causal pairing or multiplayer correctness.
No capability was promoted just for this alpha publication.

## Audit and Reproduction

[Evidence access](../research/EVIDENCE_ARCHIVE.md) explains original hashes,
public derivatives, withheld materials, source bindings and restoration.
Failures, interruptions, superseded SDKs and correction passes belong in the
index. Some historical batches were produced from dirty worktrees: where an
exact source snapshot/commit cannot be established, it remains unknown. The
publication checkpoint does not retroactively make those runs clean or signed.

Game executables, raw saves, private state, credentials and uncleared third-party
resources are not publicly redistributed. Reproducing binary analysis requires
the auditor's own matching legal installation, checked against recorded hashes.
Independent findings, including more efficient recovery methods and evidence
that contradicts our conclusions, are welcome.

## Compatibility Deliberately Retained

`iag` imports/classes, `IAG1`/`IAGUI1` and other wire identifiers, environment
variables, existing configuration directories, service/executable internal
names and current Application/Mod versions remain stable. Platform version,
Application version, Mod version and protocol revision are separate concepts.
Existing copyright, GPL-3.0-only, CC-BY-SA-4.0, MIT notices and DCO 1.1 remain.

The final [publication receipt](../research/EVIDENCE_PUBLICATION.json) records
the source/archive commits and completed checks. Test compilation is permitted;
the legacy `scripts/release/build_release.py` procedure is not run for this tag.
